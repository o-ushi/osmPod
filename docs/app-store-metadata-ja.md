## 概要（説明・4,000文字以内）

v1.81 のまま。変更不要。

```
osmPodは、ポッドキャストをフォルダで整理して聴くためのアプリです。

■ 番組を追加する
・番組名やムードで検索して追加
・RSSのURLを入力して追加
・Safariの共有メニューから取り込み
・Google AIに番組を提案してもらい、RSSのURLをコピーして取り込み
・端末内やDropboxなどのフォルダを番組として登録し、手持ちの音声ファイルも再生（ファイルはコピーせず、元の場所から再生します）

■ フォルダで整理する
・番組をフォルダに分けて、ドラッグで並べ替え
・並び順は、ツールバーのメニューから変更

■ 再生する
・ミニプレーヤーから再生画面を開いて操作
・おまかせ（シャッフル）再生。対象から除く番組も選べます
・端末を振ると巻き戻し。秒数は再生オプションで選べます
・エピソードのダウンロード、お気に入り、リピート再生
・電波が弱く再生が止まっているときは「接続待ち」と表示し、自動で読み込み直します
・番組の配信元からの読み込みが遅いときは「配信元が遅い」と表示。ダウンロードしてから聞くと確実です

■ そのほか
・エピソードの検索
・iCloudで、同じApple IDのiPhone・iPad間の番組・フォルダ・再生状態を同期（任意）
・ライブラリの書き出し・取り込み
・日本語・英語・ベトナム語に対応

■ プラン
FREEプランでは番組を3件、フォルダを5件まで登録できます。PREMIUMにアップグレードすると無制限になります。
```

## App Privacy（申告の参考メモ）

※ Apple の質問画面への回答用。文案そのものではありません。v1.83 で変更なし（前バージョンの回答のまま）。
詳細は `docs/app-store-privacy-checklist.md` と `docs/privacy-policy-ja.md`。

| 項目 | 内容（v1.80 から変わらず） |
|------|-----------|
| 番組検索 | 検索語を iTunes Search API（Apple）へ送信。任意 |
| Google AI で番組を探す | 入力した話題を含む依頼文を Google へ。毎回確認してから送信。任意 |
| RSS・音声・画像 | 各番組の配信元・CDN へ直接接続（IP アドレス等が伝わる場合あり） |
| iCloud 同期 | 番組・フォルダ・再生状態を iCloud（Apple）で同期。任意 |
| ファイル・フォルダの登録 | ファイルはコピーせず、File Provider（Dropbox 等）経由で元の場所から再生 |
| 再生ログの共有 | 開発者向けメニューからユーザーが選んだときだけ。内容を共有前に表示 |
| トラッキング・広告・解析 SDK | なし |
| v1.81 の追加分 | 受信速度は AVPlayer が端末内で記録している値を読むだけ。収集・送信なし |
| v1.82 の追加分 | ヘルプの文言のみ。送信先の追加なし |
| v1.83 の追加分 | 再生の準備処理の共通化のみ。送信先の追加なし |
